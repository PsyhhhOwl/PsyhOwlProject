# Совёнок / PsyhOwl

Telegram Mini App и бот с голосовым AI‑собеседником для психологической поддержки.

## Что уже есть

- премиальный mobile-first Mini App;
- Telegram-авторизация с проверкой `initData`;
- голос → распознавание → ответ → синтез речи;
- текстовый чат и история диалогов;
- paywall Tribute на 12 990 ₽ / 30 дней;
- проверка HMAC-подписи Tribute webhook;
- дневник, check-in настроения и короткие практики;
- админ-панель: администраторы, ручной доступ, блокировка, статистика;
- администраторы всегда получают бесплатный доступ;
- кризисный safety-flow и честные ограничения AI-сервиса;
- Dockerfile и `/health` для Timeweb Cloud App Platform.

> Совёнок не является медицинской услугой, не ставит диагнозы и не заменяет врача или психотерапевта.

## Быстрый запуск в Timeweb Cloud

1. В App Platform выберите **Docker → Dockerfile**.
2. Репозиторий: этот репозиторий, ветка `main`.
3. Путь до проекта оставьте пустым: `Dockerfile` находится в корне.
4. Путь проверки состояния: `/health` (необязательно — он уже задан в Dockerfile).
5. Добавьте переменные из `.env.example`.
6. После первого успешного деплоя укажите фактический домен в `APP_BASE_URL` и перезапустите деплой.
7. В `@BotFather` настройте Menu Button / Main Mini App на `APP_BASE_URL`.
8. В Tribute укажите webhook: `https://ВАШ-ДОМЕН/tribute/webhook`.

## Обязательные переменные

- `APP_BASE_URL`
- `SECRET_KEY`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_WEBHOOK_SECRET`
- `OWNER_TELEGRAM_ID`
- `OPENAI_API_KEY`
- `TRIBUTE_PAYMENT_URL`
- `TRIBUTE_API_KEY`

## База данных

Для быстрого теста приложение запустится на SQLite. Для продакшена задайте PostgreSQL URL:

```env
DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:5432/DBNAME
```

SQLite внутри контейнера может потеряться при пересборке или переносе приложения, поэтому подписки и история должны храниться в PostgreSQL.

## Tribute

Webhook проверяется по заголовку `trbt-signature` через HMAC-SHA256 с `TRIBUTE_API_KEY`. Поддерживаются события подписки и цифрового продукта, содержащие `telegram_user_id`.

## Материалы для психологической базы

Встроен безопасный базовый prompt на основе общепринятых навыков КПТ, ACT, DBT, клиент-центрированного подхода и мотивационного интервьюирования. Для лицензированных материалов можно создать OpenAI Vector Store и указать `OPENAI_VECTOR_STORE_ID`; тогда модель сможет использовать их через File Search.

Не загружайте в базу материалы, на использование которых у вас нет прав.
